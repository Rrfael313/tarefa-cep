# Cadastro com consulta de CEP

Projeto de formulário de cadastro que consulta o ViaCEP e salva os dados no `localStorage`.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra `index.html` no navegador (ou use a extensão Live Server).

## Funcionalidades

- Formulário com dados pessoais e endereço.
- Consulta automática ao ViaCEP quando os oito números do CEP são informados.
- Preenchimento automático de rua, bairro, cidade e estado.
- Salvamento automático dos campos no `localStorage`.
- Restauração dos dados ao abrir ou recarregar a página.

## Observação

Os dados ficam salvos somente no navegador e dispositivo usados. Não são enviados para um servidor.
